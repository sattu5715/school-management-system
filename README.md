# School Management System
स्वामी विवेकानंद पब्लिक कान्वेंट स्कूल सरायसादी, घोसी, मऊ

यह एक free, mobile-friendly School Management System starter project है।
Features: Dashboard, Students, Attendance, Fees, Exams/Results, Notices.

## Run
1. `index.html` खोलें।
2. GitHub Pages पर publish किया जा सकता है।
3. Android APK बनाने के लिए इसी web app को Capacitor/WebView project में package किया जा सकता है.
